# Step1 基于字节产品 vtable 写一个列表组件

vtable 的官方网址是：https://visactor.com/vtable、https://github.com/VisActor/VTable vtable 中有两种表形态：透视表、明细表，我们的组件采用明细表形态。建立这个组件的目的是仅仅通过最少的配置开发出可以使用的列表组件。

## 输入参数说明

参数 config：列表相关配置，如列表列标题、列宽度、列的渲染行为等等参数 data：列表数据数组

需要注意的地方：如果仅仅参数 data 改变，在组件只进行局部数据部分刷新，列表表头等非数据部分不刷新。

### 输入参数 config 说明：

| 参数 | 说明 | 类型 | 默认值 |
| --- | --- | --- | --- |
| grid_columns | 列表列（详细配置参照下面 grid_columns 配置说明） | array | - |
| allowFrozenColCount | 可选做冻结的前几列 | array | 0 |
| frozenColCount | 初始冻结列数 | array | 0 |
| showFrozenIcon | 是否显示冻结图标 | array | true |

需要注意的地方：可以扩展 vtable 的其他参数，但需要有默认值，这样可以让使用者仅仅通过最少的配置开发出可以使用的列表组件。

### grid_columns 配置说明

| 参数  | 说明         | 类型             | 默认值 |
| ----- | ------------ | ---------------- | ------ |
| title | 列头显示文字 | string           | -      |
| field | 数据 key     | string           | -      |
| width | 列宽度       | number 或 string | auto   |
| sort  | 是否开启排序 | boolean          | false  |

### 输入参数 data 说明：

| 参数 | 说明     | 类型  | 默认值 |
| ---- | -------- | ----- | ------ |
| rows | 列表数据 | array | -      |
