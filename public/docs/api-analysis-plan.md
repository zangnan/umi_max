# 日志分析监控大屏实现计划

## 需求概述

基于 `public/docs/api-analysis.md` 中的 8 个接口，创建一个日志分析监控大屏页面。

## 核心设计

采用**监控大屏**布局，使用网格化卡片展示所有图表数据，每个图表下方或旁边展示对应的原始数据表格。

## 实现细节

### 1. API 服务文件

**文件**: `src/services/apiAnalysis.ts`

创建 8 个接口调用函数，统一处理响应格式。
基础路径使用 `myUtil.api.getApiRoot()` 前缀。

### 2. 页面组件

**文件**: `src/pages/ApiAnalysis/index.tsx`

使用 `@ant-design/pro-components` 的 `ProCard` 实现网格布局：

- **顶部指标卡**: 6 个统计卡片 (StatisticCard)
- **趋势分析**: 双折线图（调用量 + 响应时间）
- **接口统计**: 柱状图 + 展开/收起数据表格
- **响应码分布**: 饼图 + 错误详情表格
- **用户/IP 统计**: 柱状图 + 数据表格
- **性能分析**: 慢接口表格 + 响应时间分布图
- **时段分析**: 24小时折线图 + 峰值标注
- **日志列表**: 分页表格

**交互设计**: 每个图表区域提供"查看数据"按钮，点击展开显示原始数据表格。

### 3. 路由配置

**文件**: `config/routes/routes.ts`

```typescript
{ name: '日志分析', icon: 'LineChartOutlined', path: '/apiAnalysis', component: './ApiAnalysis' }
```
