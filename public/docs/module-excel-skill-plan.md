# Skill 设计计划：模块 Excel 配置生成器

## Context

用户需要一个 AI 驱动的模块设计 skill。根据用户描述的业务需求（如"企业人员管理"），自动完成：
1. 表设计（数据库表结构）
2. 模块设计（页面配置）
3. 字段设计（列表/筛选/表单）
4. 菜单设计（路由和权限）

最终生成符合 `node_module.xlsx` 模板格式的 Excel 配置文件。

## 设计目标

创建一个**AI 驱动的交互式设计助手**，用户只需描述业务需求，Skill 自动推导并生成完整的模块配置，中途通过提问确认细节。

## Sheet 关联关系

```
表 Sheet                              字段 Sheet
├─ 表名行: "表中文名 表英文名"  ──────> 数据字典(表英文名)
├─ 字段行 ──────────────────────────> 字段名称(字段名)
                                     ├─ 模块key ─────> 模块 Sheet

模块 Sheet                            菜单 Sheet
├─ 模块key ─────────────────────────> 菜单路径中的key
```

**关联总结**：
- 表 Sheet 的表英文名 → 字段 Sheet 的"数据字典"
- 表 Sheet 的字段名 → 字段 Sheet 的"字段名称"
- 模块 Sheet 的模块 key → 字段 Sheet 的模块key（首行）、菜单 Sheet 的路径
- 字段 Sheet 的"数据字典+字段名称" → 确定使用哪个表哪个字段

### Step 1: 表设计（Sheet: 表）

#### 1.1 表名行（每个表第一行）

| 列位置 | 值 | 说明 |
|--------|-----|------|
| A (字段) | `表中文名 表英文名` | 格式要求：中文名和英文名用空格分隔 |
| B-G | 空 | 其他列留空 |

**示例**: `进货明细 eg_mts_tsjh`

#### 1.2 字段行

| 序号 | 列名 | AI 设计要点 | 验证规则 | 示例 |
|------|------|-------------|----------|------|
| 1 | 字段 | 小写英文+数字+下划线，^[a-z][a-z0-9_]*$ | 必填 | `uuid`, `emp_name` |
| 2 | 字段中文名 | 中文描述 | 必填 | `员工姓名`, `入职日期` |
| 3 | 数据类型 | 根据业务选择合适类型 | 必填 | `varchar(32)`, `datetime`, `decimal(10,2)` |
| 4 | 键 | 仅主键字段填 `p_key` | 可选 | `p_key` |
| 5 | 默认值 | **暂不录入**，保持为空 | - | - |
| 6 | 非空 | 必填字段填 `Y` | 可选 | `Y` |
| 7 | 备注 | 额外说明 | 可选 | |

**常用数据类型**:
- `varchar(n)`: 变长字符串，n 为最大长度，如 varchar(32)、varchar(500)
- `char(n)`: 定长字符串，适合固定长度如状态码，如 char(1)
- `datetime`: 日期时间
- `decimal(m,n)`: 精确数值，m 总位数，n 小数位，如 decimal(18,2)
- `int(n)`: 整型数字，n 为位数，如 int(10)
- `long`: 长整型 ID，无需长度

**AI 设计原则**:
- 主键统一用 `uuid` 或 `{表名}_id`
- 状态字段用 `char(1)`
- 金额/数量用 `decimal(m,n)`
- 整型数字用 `int(n)`
- 时间字段用 `datetime`

## 8. 字段设计规则（与系统 f.tsx 同步）

### 8.1 字段类型判断

| 类型关键词 | 类型分类 |
|-----------|---------|
| decimal、int、bigint、tinyint、double | 数值 |
| date | 日期 |
| char | 字符 |

### 8.2 字段 37 列配置规则

#### 列表项配置

| 列名 | 主键 | 数值类型 | 日期类型 | 含名称/备注/用途 | 默认 |
|------|------|----------|----------|------------------|------|
| 列表项开启标识 | `1` | `1` | `1` | `1` | `1` |
| 列表项主键标识 | `1` | - | - | - | - |
| 列表项对齐方式 | - | `R` | - | - | - |
| 列表项列宽 | - | `140` | `150` | `180` | `100` |
| 列表项固定列 | - | - | - | - | - |
| 列表项隐藏标识 | `1` | - | - | - | - |
| 列表项超出隐藏 | - | - | - | `1` | - |
| 列表项格式化列 | - | `0,0` 或 `0,0.xxxx` | `YYYY-MM-DD` | - | - |
| 列表项排序开关 | - | `1` | `1` | `1` | `1` |

#### 筛选项配置

| 列名 | 规则 |
|------|------|
| 筛选项类型 | **绑定第一个非Hidden表单类型的字段**，与其 form_type 相同 |
| 筛选项位置 | **默认不录入**，除非用户要求 `工具栏` 或 `列表头` |

**绑定规则说明**（与 f.tsx 264-277 行同步）：
1. 遍历字段配置，找到第一个 `form_type` 不等于 `Hidden` 的字段
2. 将该字段的 `filter_type` 设置为与 `form_type` 相同的值
3. 跳过后续字段处理（只绑定一个字段）

**示例**：
```
模块首行: "企业员工管理 eg_m_hr_employee"
  字段1: uuid     → form_type = Hidden    → 跳过
  字段2: emp_code → form_type = Input     → ✅ 匹配！filter_type = Input
  字段3: emp_name → form_type = Input     → 不处理（已绑定第一个）
```

#### 表单配置

| 列名 | 主键 | 数值类型 | 日期类型 | 非空(非主键) | char类型 |
|------|------|----------|----------|--------------|----------|
| 表单项开启 | `1` | `1` | `1` | `1` | `1` |
| 表单项类型 | `Hidden` | `InputNumber` | `DatePicker` | - | `Input` |
| 表单项格式化 | - | 同列表格式化 | `YYYY-MM-DD` | - | - |
| 表单校验规则 | - | `number(总长度,小数位)` | - | `必录` | `varchar2(长度)` |

### 8.3 格式化规则

**数值格式化**:
- `decimal(18,2)` → `0,0.00`
- `decimal(10,0)` → `0,0`
- `int(10)` → `0,0`

**字符长度校验**:
- `varchar(32)` → `varchar2(32)`
- `char(1)` → `varchar2(1)`
