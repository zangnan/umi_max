# 模块 Excel 配置生成器

AI 驱动的交互式设计助手。用户只需描述业务需求（如"企业员工管理"），Skill 自动推导并生成完整的模块配置 Excel 文件。

## 模板文件

- 位置: `public/import_template/v0.2node/node_module.xlsx`
- Sheet 结构: 表、模块、字段、菜单、自定义SQL、自定义码表
- 当前阶段处理: 表、模块、字段、菜单（4个 Sheet）

## 格式规范

与模板保持一致：
- **字体**: Microsoft YaHei, 9pt
- **表头样式**: 粗体 + 浅灰色背景 (FFD9D9D9)
- **模块表头**: 浅绿色背景 (FFEBF1DE)
- **边框**: 所有单元格四边 thin
- **对齐**: 左对齐

## 工作流程

### Step 1: 表设计

**收集信息**:
- 表中文名 + 表英文名（格式: `中文名 表英文名`）
- 字段列表（字段名、中文名、数据类型、键、默认值、非空、备注）

**字段验证规则**:
- 字段名: `^[a-z][a-z0-9_]*$`（小写英文+数字+下划线）
- 字段中文名: **必填**，不能为空
- 数据类型: `varchar(n)`, `char(n)`, `decimal(m,n)`, `int(n)`, `datetime`, `long`

### Step 2: 模块设计

**31 列配置**，关键项：

| 配置项 | 可选值 | 说明 |
|--------|--------|------|
| 列表边框 | `1` | |
| 列表首选项 | `checkbox`/`radio`/空 | |
| 工具栏按钮 | `1`/空 | 增加/删除/编辑/导入/导出/设置/全屏/刷新/筛选 |
| 工具栏导出 | `1`/`1,pdf`/`2` | `1`前端导出，`2`后端导出 |
| 表单布局 | `horizontal`/`vertical`/`4` | 水平/垂直/四列 |
| 表单宽度 | `960`/`1200`/`max` | |
| 自定义按钮 | `按钮名&方法名&参数` | 多值逗号分隔 |

### Step 3: 字段设计

**37 列配置**，按字段循环。

**Sheet 结构**:
- 每组第一行: `模块名称 模块key`（如 `企业员工管理 eg_m_hr_employee`）
- 后续行: 该模块每个字段的配置

**主键和外键字段隐藏规则**:

| 字段类型 | 键属性 | 字段名特征 | 列表项隐藏标识 |
|----------|--------|------------|----------------|
| 主键字段 | `p_key` | - | `1` |
| 外键字段 | 空 | 以 `_uuid` 结尾 | `1` |

**关键配置**:

| 类别 | 配置项 | 可选值 |
|------|--------|--------|
| 列表 | 列宽、对齐、固定、隐藏、排序、统计 | `120`, `L`, `1` |
| 筛选 | 类型、位置、占位符 | 类型: `Input`, `Select`, `DatePicker`; 位置: 空/`工具栏`/`列表头` |
| 表单 | 类型、格式化、只读、验证 | `必录`, `电话`, `邮箱` |

**格式化类型**:
- 日期: `YYYY-MM-DD`
- 数值: `0,0.00`
- 开关: `switch:0,1`
- 树结构: `tree:key`
- 码表: `code_dm_xxx`

**字段初始排序**: `asc,10` / `desc,20`（升序/降序 + 优先级）

## 输出文件

- **命名**: `{模块名称}_{模块key}_{timestamp}.xlsx`
- **目录**: `./exports/module_configs/`
- **格式**: 与模板一致（字体、背景色、边框、列宽）

**多模块合并规则**：
- 除非用户明确说明要分成多个文件，否则多个模块应生成到**一个 Excel 文件**
- 使用 `--groups` 参数指定主子表关系：`Master|Detail1,Detail2;Standalone`
  - `|` 前是主表，后面逗号分隔的表为子表
  - `;` 分隔多个组
  - 无 `|` 的表名为独立模块
- 示例：`--groups "人员管理|人员学历管理,人员工作经历管理;发票管理|发票明细管理;部门管理;考勤管理"`

## 验证检查

生成 Excel 后检查：
1. 4个 Sheet 完整（表、模块、字段、菜单）
2. 每个 Sheet 有表头行
3. 表 Sheet: 有表名行 + 字段行
4. 模块 Sheet: 有模块配置行
5. 字段 Sheet: 有模块首行 + 字段配置行
6. 菜单 Sheet: 有菜单层级结构
7. 列宽与模板一致

## 主子表模块（Master-Detail）

主子表是一种"数据列表+数据采集"的扩展模式，用于维护一对多关系的数据。

### 场景示例

- 员工（主表）+ 学历（子表）+ 工作经验（子表）
- 发票头（主表）+ 发票明细（子表）
- 报关单头（主表）+ 报关单明细（子表）

### 分隔行（leaf）规则

主子表通过字段 Sheet 中的分隔行（leaf）实现关联。分隔行是列表中的虚拟列，点击后展开子表数据。

**分隔行字段配置（37列）**：

| 列索引 | 列名 | 值 | 说明 |
|--------|------|-----|------|
| 1 | 数据字典 | **空** | 分隔行特征：此项为空 |
| 2 | 字段名称 | **空** | 分隔行特征：此项为空 |
| 3 | 字段中文名 | `教育经历` | 显示文本 |
| 13 | 列表项格式化 | `leaf:eg_m_staff_education&staff_name` | 格式：`leaf:<子模块key>&<关联显示字段>` |
| 25 | 表单项开启 | **空** | 分隔行不是数据字段 |
| 26 | 表单类型 | **空** | 分隔行不是数据字段 |
| 27 | 表单格式化 | **空** | 分隔行不是数据字段 |

**leaf 格式说明**：
- 语法：`leaf:<子模块key>&<关联显示字段>`
- 示例：`leaf:eg_m_staff_education&staff_name`
- 表示：点击此分隔行，展示 `eg_m_staff_education` 子模块，标题使用 `staff_name` 字段

**分隔行文本推断规则**：
| 表名特征 | 推断文本 |
|----------|----------|
| 以"教育"、"学历"、"学习"结尾 | `教育经历` |
| 以"工作"、"履历"、"经历"结尾 | `工作经历` |
| 以"荣誉"、"奖励"、"称号"结尾 | `荣誉` |
| 以"明细"、"详情"结尾 | `明细` |
| 其他 | 表中文名最后4字 |

### Sheet 写入规则

| Sheet | 是否包含分隔行 | 说明 |
|-------|---------------|------|
| 表 | **否** | 分隔行是字段 Sheet 的虚拟列，不写入表 Sheet |
| 模块 | - | 每组表对应一个模块 |
| 字段 | 是 | 分隔行写入字段 Sheet |
| 菜单 | - | 只需为主表创建菜单 |

### 主子表字段 Sheet 结构

```
行1: 表头 (37列)
行2: 模块首行: 企业员工 eg_m_staff
行3: staff_uuid, 员工UUID, ...
行4: staff_code, 员工编号, ...
行5: staff_name, 员工姓名, ...
...
行8: (空), (空), 教育经历, ..., leaf:eg_m_staff_education&staff_name, ...  ← 分隔行

行10: edu_uuid, 教育经历UUID, ...

...
```
