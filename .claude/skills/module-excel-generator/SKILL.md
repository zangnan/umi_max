# 模块 Excel 配置生成器

AI 驱动的交互式设计助手。用户只需描述业务需求（如"企业员工管理"），Skill 自动推导并生成完整的模块配置 Excel 文件。

## 模板文件

- 位置: `public/import_template/v0.2node/node_module.xlsx`
- Sheet 结构: 表、模块、字段、菜单、自定义SQL、自定义码表
- 当前阶段处理: 表、模块、字段、菜单（4个 Sheet）

## 格式规范

与模板保持一致：
- **字体**: Microsoft YaHei, 9pt
- **表头样式**: 粗体 + 浅灰色背景 (FFD9D9D9)
- **模块表头**: 浅绿色背景 (FFEBF1DE)
- **边框**: 所有单元格四边 thin
- **对齐**: 左对齐

## Sheet 结构

| 行 | 内容 | 说明 |

| 2 | 表名行: `表中文名 表英文名` | 如 `企业员工 hr_employee` |

| 3+ | 字段配置行 | 每个字段一行 |

### Sheet 4: 菜单

## 工作流程

### Step 1: 表设计

**收集信息**:
- 表中文名 + 表英文名（格式: `中文名 表英文名`）
- 字段列表（字段名、中文名、数据类型、键、默认值、非空、备注）

**字段验证规则**:
- 字段名: `^[a-z][a-z0-9_]*$`（小写英文+数字+下划线）
- 数据类型: `varchar(n)`, `char(n)`, `decimal(m,n)`, `int(n)`, `datetime`, `long`

### Step 2: 模块设计

**31 列配置**，关键项：

| 配置项 | 可选值 | 说明 |
|--------|--------|------|
| 列表边框 | `1` | |
| 列表首选项 | `checkbox`/`radio`/空 | |
| 工具栏按钮 | `1`/空 | 增加/删除/编辑/导入/导出/设置/全屏/刷新/筛选 |
| 工具栏导出 | `1`/`1,pdf`/`2` | `1`前端导出，`2`后端导出 |
| 表单布局 | `horizontal`/`vertical`/`4` | 水平/垂直/四列 |
| 表单宽度 | `960`/`1200`/`max` | |
| 自定义按钮 | `按钮名&方法名&参数` | 多值逗号分隔 |

### Step 3: 字段设计

**37 列配置**，按字段循环。

**Sheet 结构**:
- 每组第一行: `模块名称 模块key`（如 `企业员工管理 eg_m_hr_employee`）
- 后续行: 该模块每个字段的配置

**关键配置**:

| 类别 | 配置项 | 可选值 |
|------|--------|--------|
| 列表 | 列宽、对齐、固定、隐藏、排序、统计 | `120`, `L`, `1` |
| 筛选 | 类型、位置、占位符 | 类型: `Input`, `Select`, `DatePicker`; 位置: 空/`工具栏`/`列表头` |
| 表单 | 类型、格式化、只读、验证 | `必录`, `电话`, `邮箱` |

**格式化类型**:
- 日期: `YYYY-MM-DD`
- 数值: `0,0.00`
- 开关: `switch:0,1`
- 树结构: `tree:key`
- 码表: `code_dm_xxx`

**字段初始排序**: `asc,10` / `desc,20`（升序/降序 + 优先级）

### Step 4: 菜单设计

**15 列配置**：

| 配置项 | 格式要求 | 示例 |
|--------|----------|------|
| 菜单id | 数字，层级式编码 | `1010` |
| 父级菜单id | 父级菜单ID | `10` |
| 菜单名称 | 中文名称 | `企业员工管理` |
| 菜单路径 | `/dynamicbs1/cfgp/{模块key}` | `/dynamicbs1/cfgp/eg_m_hr_employee` |
| 组件 | `./common/automatic_page` | 页面组件 |
| 菜单类型 | `1`(页面)/`9`(按钮) | `1` |
| 角色 | 逗号分隔 | `管理员,HR` |

**组件路径规范**:
- 普通页面: `./common/automatic_page`
- 树状页面: `./common/automatic_page_tree`
- 树+列表页面: `./common/automatic_page_tree_grid`

**菜单 ID 编码**:
- 顶级: `10`, `20`, `30`
- 二级: `1010`, `1020`
- 三级: `101010`, `101020`
- 按钮: `1010101`

## 输出文件

- **命名**: `{模块名称}_{模块key}_{timestamp}.xlsx`
- **目录**: `./exports/module_configs/`
- **格式**: 与模板一致（字体、背景色、边框、列宽）

## 验证检查

生成 Excel 后检查：
1. 4个 Sheet 完整（表、模块、字段、菜单）
2. 每个 Sheet 有表头行
3. 表 Sheet: 有表名行 + 字段行
4. 模块 Sheet: 有模块配置行
5. 字段 Sheet: 有模块首行 + 字段配置行
6. 菜单 Sheet: 有菜单层级结构
7. 列宽与模板一致
